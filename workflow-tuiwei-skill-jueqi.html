“

还在把 画布 当核心能力，你不是走在前面，是在给一个正在 退场的范式 续命。

我知道这个判断会让一批人不舒服。但事情已经很清楚了：如果你现在还把”画一张漂亮的 workflow“当成 AI 产品的核心能力，你不是走在前面，你是在给一个正在退场的范式续命。

而最能说明问题的信号是——就连当年靠 workflow 画布起家的扣子，都已经转身了。

01

AN AWKWARD FACT

一个尴尬的事实

2025 年下半年，我身边做 AI 应用的朋友们，集体安静了。

不是那种”闷声发财“的安静，而是那种”不好意思再提自己在画什么“的安静。具体表现是：以前群里天天晒的 workflow 截图消失了。那些曾经花花绿绿的节点连线、二十几步的自动化流程图、带着”我做了个牛逼 bot“自豪感的朋友圈——全部蒸发了。

为什么？因为他们发现，隔壁那个从不画流程图的家伙，用一个 AI Agent 工具对话三句话搞定的事情，他们画了半小时节点才跑通。而且跑通之后，稍微换个场景就得重新画。

这种体验落差一旦被感知到，就再也回不去了。

就像你用过 iPhone 之后，没人能让你回去用塞班手机——不是塞班不能打电话，是你的手已经记住了更好的交互方式。

— 一张打了红叉的复杂画布：workflow 正在退位


02

THE MISPLACEMENT

把”搭建过程“当成了产品

让我们说点不客气的话。Workflow 范式最大的问题不是技术不行，不是模型不够强，甚至不是产品设计不好看。

「它把”构建过程“当成了核心价值，而不是把”完成任务“当成核心价值。」

打开一个典型的 workflow 平台，你首先看到的是一个空白的画布。它在暗示你：来吧，开始搭建吧。但用户打开一个 AI 工具的时候，脑子里想的是”帮我把这件事做了“，不是”给我一个空画布让我画图“。这是一个致命的错位。

— 空白画布的错位：用户要的是结果，不是画笔

它的逻辑是”我给你乐高积木，你搭出你想要的东西“。这在 2024 年是对的，因为当时画 workflow 至少比写代码门槛低。但这个逻辑有一个隐含假设——用户愿意花时间搭建。2025 年的用户已经不愿意了。

他们见过了另一种可能：我说一句话，AI 自己去调度工具、读写文件、查资料、写代码、验证结果。全程不需要我提前规划任何步骤，因为 AI 遇到岔路口的时候会自己判断。它们不给你画布，给你一个对话框——你说你要什么，它去做。你猜用户选哪个？


03

A NOTE OF DISTRUST

Workflow 是一份”不信任书“

我们来做一个思想实验。你雇了一个助理，名校毕业、经验丰富、反应敏捷。然后你给他打印了一份 200 步的操作手册，要求他严格按顺序执行，不许跳步，不许变通。你觉得这是”赋能“还是”侮辱“？

— 一份不信任书：把判断力浪费在流程清单里

这就是 workflow 对大模型做的事。2023 年的大模型确实像刚毕业的新人，需要手把手带。但到了 2025 年下半年，主流模型的规划、工具调用、错误恢复能力已经过了质变的临界点。你还在给它画流程图，就像给一个工作三年的资深员工贴任务清单。

更讽刺的是，workflow 的存在反而会降低系统的整体能力。你预设的分支逻辑永远覆盖不了真实世界的所有情况；意外 case 一出现，要么走进死分支报错，要么给出离谱结果。而没被束缚的 agent 可以即时推理、灵活应对。

「所以 workflow 不只是”多余的一层“，它积极地在损害系统表现。」


04

THE STRONGEST SIGNAL

连旗手都转身了

如果说前面的论证还带着点”我的判断“，那么接下来这件事，是硬邦邦的行业事实。曾经把”画布 + 插件市场“做到极致、几乎定义了国内 workflow 心智的扣子，已经悄悄换了一副面孔。

现在打开它，迎接你的不再是一张让你连节点的空白画布，而是一个会自我介绍的 AI 搭档：支持多人多 Agent 组队协作、能接管复杂的编程与视频创作、你说一句话它去调度和干活。它不再要求你先学会”画流程图“，而是让你直接说人话。

— 旗手转身：连大船都调转了船头

旗手比任何人都更清楚风往哪边吹。

这不是”谁被谁打败了“的故事，而是一次集体的范式迁移：连最有理由坚守画布的玩家，都选择了退位让路。


05

THE TWILIGHT

插件市场的黄昏

Workflow 时代的第二根支柱——插件市场——也在加速贬值。2024 年，”我们有 3000 个插件“是一句很有力的卖点。但 MCP 协议的普及正在让”插件“这个概念本身变得可笑。

MCP 的逻辑是：任何服务只要暴露一个标准接口，agent 就能直接调用。不需要有人提前封装成插件、不需要上架市场、不需要用户搜索和安装。那些辛苦运营的”插件生态“，全部会变成一层多余的中间层。

— 插件市场的黄昏：厚黄页正在被去中介化

「插件市场就是 AI 时代的黄页。它正在被去中介化。」

一个类比：MCP 之于插件市场，就像互联网之于电话黄页。当你可以直接搜索到任何商家的时候，没有人再需要翻那本厚厚的黄页了。而那些靠黄页广告赚钱的公司，一夜之间失去了商业模式。


06

WHY SKILL RISES

Skill 为什么会崛起

2025 年，一系列以”agent 原生“为底层架构的产品密集出现。它们的共同特点是：没有 workflow 画布，没有插件市场，用户打开就是一个对话界面。这类产品的杀手锏不是某个单点功能强，而是把使用门槛压到了零。

你不需要理解”节点“”触发器“”变量“”条件分支“这些术语。你只需要会说人话——准确描述你要什么结果——agent 负责剩下的一切。而真正让它可持续的，是底层单元变了：从 workflow 换成了 skill。

过程知识 vs 领域知识

Workflow 编码的是”过程知识“——它把”这件事应该按哪些步骤做“固化下来。这种知识很脆：换个场景、换个数据、换个边界条件，整条流程就得重画。

Skill 编码的是”领域知识“——它把”在这个领域里怎么把事做好“沉淀下来，至于具体走哪几步，交给 agent 当场判断。这种知识鲁棒，而且可组合。


07

LINEAR VS EXPONENTIAL

线性 vs 指数

这就引出了两种范式最本质的分野：能力增长曲线完全不同。Workflow 平台的能力增长是线性的：你每做一个新 workflow，只解决一个特定场景。做一百个，解决一百个。

Skill 驱动的 agent，能力增长是指数的：每沉淀一个新 skill，它可以被无数种组合方式调用。今天是”数据分析“+”图表设计“，明天可能是”竞品调研“+”PPT 生成“。组合方式不是预先设计的，是 agent 根据任务需要即时决定的。

一个是加法，一个是乘法。时间拉长，差距不是拉开，是碾压。


08

NOT DEATH

退位，不等于死亡

「Workflow 退位，不代表消失。它只是从”前台的主角“退到了”幕后的机制“。」

在底层，用 workflow 来保证某些关键流程的确定性仍然有价值——比如涉及资金、合规、审批的环节，你确实需要一条不会乱跳的确定路径。但这属于系统内部的实现细节，不该再暴露给用户，更不该成为一个产品对外标榜的核心卖点。

— 退位不等于死亡：一扇门关上，一扇窗透进光

面向用户的交互层，全部应该切换成自然语言对话 + 意图描述。这条路难就难在，它要求一个团队先承认：”我们过去两年最引以为傲的东西，位置放错了。“在一个大组织里，这种自我否定需要的勇气，远超技术层面的挑战。能转身的，都值得尊敬。


∞

THE END

结语

有人会说 workflow 曾经很伟大。这我完全承认——它降低了 AI 应用的门槛、培育了开发者生态、让很多非技术人员第一次体验到”自己做 AI 产品“的成就感。这些都是真实的功劳。

「做对过去的事情，不能保护你免于被未来重新定义。」

诺基亚做对了功能机的一切，柯达自己发明了数码相机。区别只在于——有人及时转身，有人没有。方向变了，执行力越强，跑错方向就越远；但只要肯转身，就还在牌桌上。

Workflow 退位的时代已经到来。潮水退去的时候，你是穿了泳裤还是没穿，只是一个时间问题。而 skill 与 agent——那些直接帮用户干活、不需要用户先学会画图的能力单元——正在安安静静地，把一切重新组织起来。
