§01 · 飞书十年

从「连日历都没有」
到全球版本。

这是我在字节跳动至今，
憋得最长时间的产品。

2016 年飞书立项时，梁汝波正好负责技术。2017 年初的设计图里，只有最基础的消息功能，连日历都没有。做过免费、付费、开源、闭源各种方案之后，他们甚至认为这件事限制了公司发展，才在 2016 年下定决心。做 ToC 产品，从立项到发布一般 3 个月；飞书，用了 3 年。

十年间，飞书支撑了字节内部的协作，也收获了一路陪伴的企业客户。

§01 · 十年 / TEN YEARS产品老A
§02 · 年度关键词

今年，字节只一个字：
勇攀高峰。

高峰不常有，过去每次隔了
15–20 年，机会难得，
必须勇攀高峰。

—— 勇攀高峰

字节跳动每年都会定一个年度关键词，用来指引一年的工作。今年定的是「勇攀高峰」。梁汝波用它来解释：为什么此刻要把三股力量合到一起，为什么此刻容不得松懈。

§03 · 四座高峰 / FOUR PEAKS产品老A
§04 · 危机感

攀上一次高峰，
下一座来时也可能掉下来。

Google 是在 Web 这座高峰成功的。
但每一次高峰更替，都伴随掉队。

「过去每次高峰都间隔 15–20 年，登上旧峰不代表能保住位置。我给团队讲这张图，主要是想强调危机感。」机会难得，而技术周期的切换，从不为谁停留。

§04 · 危机感 / URGENCY产品老A
§05 · 办公协同

办公协同，每轮变革
都被重新创造。

  1. Office
    PC 时代，办公协同就是核心应用。
  2. Office 365
    Web 时代，被重新做了一遍。
  3. Teams
    Mobile 与云时代，再次易主。三次变革里，Office 的地位甚至比对 Windows 还稳固。

「飞书算是从 Mobile 时代上了车。希望在 AI 时代，飞书能充分抓住属于它的机会。」这一次变革更大，更可能出现质的飞跃。

§05 · 重做 / REBUILT产品老A
§06 · 三者融合

Agent、模型、协作环境，
必须紧密融合。

Agent 不是孤立存在的——它需要和人、工作环境以及其他 Agent 协作，能力又与模型密切相关。所以三者必须融合。落到客户身上，是两条清晰的路径：

员工让每个人用好 AI

豆包提供智能，飞书承载企业上下文与工具。两者结合，员工就能在工作场景里自然高效地用 AI，创造价值。

企业构建独有 Agent

依靠火山引擎的模型、算力与全套开发工具，把企业独有的经验打造成自己的 Agent，再接入飞书，与人和其他 Agent 协作。

§06 · 融合 / FUSION产品老A
§ 附 · 转型

AI 转型，
远不止换一套工具。

走进企业
客户成功团队与技术专家，会走进企业组织，和大家一起完成这场迁移；接下来，字节将在企业市场投入更多的资源与力量，让智能更快在组织里真正产生价值。
