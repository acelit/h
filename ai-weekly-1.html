AI WEEKLY AGENT

EDITOR'S NOTE

统计周期 11.13 — 11.20

这一周 AI 行业的变化，已经不只是模型参数、榜单和 benchmark 的竞争。更值得关注的是，AI 正在从一个「回答问题的工具」，向一个能够理解目标、调用工具、持续执行并产生商业结果的系统演进。

本期按五个固定栏目整理，重点筛选对 AI 产品经理、AI 搜索、Agent 产品和商业化 有实际参考价值的动态。

01

PART

 

全球模型发布

GLOBAL MODEL RELEASES

本周模型发布的一个明显趋势是：旗舰推理模型、低成本执行模型、专用决策模型开始形成更清晰的分层。

GEMINI Gemini 4 Carbon：高性能推理与代码能力 1 / 5
  • 面向开发者和企业用户开放。
  • 强调复杂编程、Agent 工作流、长任务处理。
  • 初始 API 定价：每百万输入 Token 2 美元、输出 10 美元（限期价格）。
  • 推向开发者、企业以及 AI Ultra 用户。

意义：Google 开始构建更细化的模型梯队，不同模型分别承担复杂推理、快速执行和高频任务。

ANTHROPIC Claude Fable 5.2 与 Mythos 5.2 2 / 5

Anthropic 本周推出两款新模型：

  • Claude Fable 5.2：面向技术工作、Agent 编程、跨代码库开发、长周期任务。
  • Claude Mythos 5.2：面向受限的高安全研究与专业场景，采用更严格的访问机制。

Fable 5.2 同时强调多步骤执行能力、复杂代码任务以及长时间运行的 Agent。

GEMINI Gemini 4 Hydrogen：高效执行模型 3 / 5
  • 专注编码、日常推理与 Agent 执行。
  • 支持百万 Token 上下文。
  • 输入价格约 1.50 美元、输出 7.50 美元，按每百万 Token 计。
  • 定位是高频、快速、成本可控的日常执行模型。

Carbon 更偏复杂任务，Hydrogen 更偏快速执行，体现 Google 的模型分层策略。

MEITUAN 美团 LongCat-2.5 开放权重 4 / 5
  • 总参数规模约 1.6 万亿。
  • 每 Token 激活参数约 480 亿。
  • 多模态 MoE 架构。
  • 开放权重，采用 MIT 许可。
  • 支持 4-bit 权重及激活量化路线。

这对企业部署与开源模型生态意义较大，尤其是大规模模型正在通过稀疏激活降低实际推理成本。

META Meta Muse Ember：小模型低成本路线 5 / 5

Meta 推出 Muse Ember，面向轻量、多模态、高频应用场景，公布的输入价格约为每百万 Token 0.10 美元。

值得关注的是，模型能力正在被商品化：分类、判断、抽取、简单推理这类任务，越来越多可以用低成本模型完成。

PART

 

AI 产品更新

PRODUCT SHIFTS

这一周比模型发布更值得关注的，是AI 产品正在从「AI 功能」变成「AI 工作入口」。

ANTHROPIC Claude Sheets、Whiteboards、Meetings、Data 1 / 4

Anthropic 在本周集中推出办公场景能力。

  Claude Sheets 

AI 数据表格与分析。

  Claude Whiteboards 

可视化协作与思维整理。

  Claude Meetings 

会议记录、行动项、会中任务。

  Claude Data 

数据仪表盘分析，正式可用。

核心变化：

  • Sheets：让 AI 直接参与数据处理与表格分析。
  • Whiteboards：从对话走向可视化内容创作与协作。
  • Meetings：进入会议过程，记录、总结、识别行动项并继续执行。
  • Data：将企业数据分析能力产品化。

Anthropic 的方向非常明确：不再只提供聊天框，而是围绕用户工作过程构建完整的 AI 工作环境。

OPENAI Businesses in ChatGPT 2 / 4

OpenAI 开始测试 Businesses in ChatGPT：

  • 企业可以创建经过验证的品牌主页。
  • 企业 Agent 可向用户提供商品信息、服务咨询。
  • 部分美国市场支持 Business Agent。
  • 结合商家商品信息，支持用户比较商品并完成购物决策。

AI 入口正在成为企业与消费者之间的新渠道，而不只是传统搜索引擎的流量入口。

REPLIT Agent 从聊天直接经营业务 3 / 4

Replit 为 Agent 新增商业任务能力：

  • 帮企业采购日常经营用品。
  • 通过 Google Ads 执行广告活动。
  • 结合 Stripe 支付授权完成商业操作。

用户可以通过对话提出目标，Agent 负责规划和执行，并在涉及交易时触发授权。

ADOBE 开放 Creative Cloud 给其他 AI Agent 4 / 4

Adobe 发布本地 MCP Server，让 ChatGPT、Claude、Gemini 等 AI 工具能够调用 Creative Cloud 的应用能力。

这意味着用户可以通过其他 AI Agent直接操作 Adobe 的创作工具，而不必每次都进入 Adobe 自己的产品入口。

Agent 技术

AGENT STACK

这一周 Agent 领域最值得关注的变化，可以概括为三个方向：长周期自主执行、Agent 交易、Agent 标准化与治理。

ANTHROPIC Claude Managed Agents：企业可在自己的云环境运行 1 / 5

Anthropic 开始向部分企业开放自托管 Claude Managed Agents。企业可以把 Agent 的运行环境部署在自己的云或数据中心，并控制：

  • Agent 运行环境与 Sandbox。
  • Session 和任务执行状态。
  • Credential 和工具权限。
  • 内部数据访问。
  • Agent 执行轨迹。

模型推理仍通过 Anthropic 服务完成，但Agent 的运行基础设施及部分关键数据由企业控制。

产品启发：企业 Agent 的核心价值正在从「模型能力」转向「模型 + 企业数据 + 执行环境 + 权限治理」。

OPENAI ChatGPT Wallet：Agent 开始拥有支付能力 2 / 5

本周 OpenAI 推出 ChatGPT Wallet，允许符合条件的 Agent 在用户授权下完成购物支付。关键机制：

  • Agent 可以帮助选择商品并生成购物车。
  • 用户审核商品和金额。
  • 用户通过生物识别确认。
  • 采用 Tokenized Payment，Agent 不直接获取真实银行卡信息。

这意味着Agent 已经开始进入交易执行环节，而不仅仅是信息推荐。

SIERRA Personal Agent Protocol 1.0 3 / 5

Sierra 发布 Personal Agent Protocol（PAP）1.0，尝试建立个人 Agent 与企业服务之间的交互标准。参与生态包括 Shopify、Stripe、Walmart、Meta 等。

目标是让用户的个人 Agent 与商家 Agent 直接对接，完成产品咨询、服务沟通、订单处理等任务，不需要每家企业都单独开发一个 Agent 接口。

如果未来 Agent Protocol 形成生态，可能会像互联网协议一样，解决 Agent 与不同企业系统之间的标准化连接问题。

DEEPMIND AlphaProof Code：Agent 开始验证真实世界代码 4 / 5

Google DeepMind 使用 AlphaProof Code 与 Gemini 4 Carbon，针对 Signal 加密协议相关代码开展形式化验证工作。

这类 Agent 不只是生成代码，而是通过形式化证明工具检查代码逻辑是否满足指定的数学性质。

它体现了一个重要趋势：AI 的价值开始从「生成内容」扩展到「证明内容、验证结果、降低错误」。

在金融、医疗、支付、软件安全等高风险场景，验证能力可能比生成能力更重要。

MERCOR Agent 评测开始产业化 5 / 5

Mercor 完成新一轮融资，估值达到 200 亿美元，持续布局企业 Agent 评测及能力验证。

Agent 评测正在从传统模型 Benchmark 扩展到：

  • 真实工作任务完成率。
  • 多步骤执行能力。
  • 长时间任务稳定性。
  • 工具调用准确性。
  • 企业工作流自动化程度。

未来可能形成独立的 Agent 评测市场。企业采购 Agent 时，不仅看模型排行榜，也会看实际岗位任务的自动化能力和可靠性。

国内 AI 动态

CHINA WATCH

本周国内值得关注的方向：国产大模型开源、模型服务商业化、AI 入口竞争、芯片产业资本化。

ALIBABA Qwen4-Max 预览持续推进 1 / 4

阿里持续推进 Qwen4-Max 的预览体验：

  • 支持百万 Token 上下文。
  • 支持图像、视频理解等多模态输入。
  • 面向复杂推理、办公、编程及 Agent 场景。
  • 通过千问 App、QwenStudio、Qoder 等不同产品入口分发模型能力。

阿里的策略不只是模型发布，也在构建模型、开发工具、C 端应用和企业服务的统一生态。

DEEPSEEK 开放应用 API 能力 2 / 4

DeepSeek 于 11 月 13 日开放应用 API 能力包，增加 Web 搜索、文件输入及 URL 读取等能力，使开发者更方便地把信息获取和内容理解能力接入应用。

对开发者而言，API 正从单纯的模型调用走向完整应用能力，减少了自行搭建搜索、文件解析等基础设施的成本。

BAIDU AI 产品生态与模型服务继续扩展 3 / 4

百度近期围绕文心模型、Agent 产品、Token 服务交易和企业 AI 应用持续推进生态建设。本周行业关注的方向包括：

  • 多模型能力开放。
  • AI Agent 产品升级。
  • 企业模型服务与交易平台。
  • AI 与医疗、搜索、办公等垂直场景融合。

这类生态竞争的关键不只是模型本身，而是能否形成从模型能力到应用入口、用户数据及商业化的闭环。

T-HEAD 阿里芯片业务资本化进程 4 / 4

阿里旗下数据中心芯片业务平头哥（T-Head）推进香港上市相关流程，阿里预计继续保持控制权，具体发行规模与结构尚未最终确定。

这反映国内 AI 产业正在形成新的资本结构：大模型、云计算、AI 芯片和数据中心基础设施成为独立竞争与资本化方向。

产品经理启发

PM TAKEAWAYS

这周的新闻，结合 AI 产品、AI 搜索、教育搜索和 Agent 方向，我认为最值得提炼的是五个产品趋势。

趋势 1：从「单模型最强」到「模型组合最优」

Gemini 4 Carbon、Hydrogen、Claude Fable、Meta Muse Ember 等产品，体现出不同模型开始明确承担不同任务。

未来 AI 产品可能不再依赖一个模型，而是构建一个模型组合体系。

这可能是教育搜索 AI Decision Layer 思路最值得继续深化的方向。

趋势 2：从 Chat UI 走向 Work UI

Anthropic 推出 Sheets、Whiteboards、Meetings，Adobe 开放 Creative Cloud，Replit Agent 直接执行商业任务。这些产品有一个共同点：

AI 不再只给用户一个答案，而是直接在用户工作的环境里完成事情。

传统 AI 产品：用户提问 → AI 回答 → 用户复制结果 → 用户继续工作。

新一代 AI Work 产品：用户提出目标 → AI 理解任务 → AI 在工作空间中执行 → 用户审阅结果 → AI 继续迭代。

这意味着 AI 产品的设计重点也将发生变化：

  • 从聊天体验转向任务体验。
  • 从答案展示转向成果展示。
  • 从单轮交互转向工作过程。
  • 从用户主动操作转向 AI 主动推进。

趋势 3：Agent 要设计完整的「任务闭环」

Agent 不应该只是一个能调用工具的 Chatbot。真正有价值的 Agent，应该具备以下六个能力环节：

01

目标理解

识别最终目标，而非只理解当前问题

02

任务规划

拆解步骤、安排优先级、确定工具

03

任务执行

调用工具、操作系统、业务系统

04

校验与授权

验证结果、风险判断、关键操作确认

05

持续迭代

根据执行结果调整方案与步骤

06

交付结果

明确任务是否完成，输出可验收成果

建议未来评测 Agent 时，不再只看回答质量，而是重点关注：

  • Task Completion Rate（任务完成率）
  • Execution Success Rate（执行成功率）
  • Tool Call Accuracy（工具调用准确率）
  • Human Intervention Rate（人工介入率）
  • Cost per Task（单任务成本）
  • Time to Completion（任务完成时间）

趋势 4：商业化的关键是「权限 + 交易 + 信任」

OpenAI Wallet、Replit 商业 Agent、Sierra Agent Protocol 都在解决一个问题：

如何让 AI 在用户授权的前提下，真正代表用户做事情？

未来 Agent 的权限设计可能分为三层：

权限等级
Agent 行为
用户控制
L1 信息权限
搜索、阅读、总结
默认授权
L2 操作权限
修改文件、创建任务、发消息
可撤销授权
L3 交易权限
支付、下单、签约等
强确认 / 限额

未来产品经理需要设计的不只是 Agent 能做什么，还包括Agent 不允许做什么、何时必须暂停、出了问题如何恢复。

趋势 5：护城河从模型转向数据与工作流

模型能力越来越容易获得，开源模型、低价 API、多模型接入不断降低技术门槛。

未来产品壁垒可能更多来自：

  • 高质量垂直数据。
  • 业务知识库与知识图谱。
  • 真实用户行为数据。
  • 复杂工作流与工具生态。
  • 用户信任及长期使用习惯。
  • 任务执行效果和反馈闭环。

对于教育 AI 来说，真正有竞争力的产品未必是「哪个模型回答得最好」，而是能否把教材、知识点、考试、题目、视频、学习行为与个性化学习路径连接起来，真正解决学习问题。

CLOSING · 本周一句话总结
