    核心概念速览

    LifeOS 的独有部件 · 全部技能都围绕它们运转

    现状 → 理想态Current State → Ideal State

    整个系统只做一件事：把你（或任意目标）从现状推向理想状态，追寻 Euphoric Surprise。

    TELOS 目标文件TELOS

    记录你的目标、信念、叙事与战略的「宪法文件」，让 AI 真正了解你并据此工作。

    算法The Algorithm

    驱动 Loop / Optimize / Ideate 的通用改进循环：评估现状、生成候选、测试、选择、再迭代。

    理想态工件 ISAIdeal State Artifact

    承载一个项目或任务「理想状态」的原语，可打分、可对账、可访谈补全。

    技能系统The Skill System

    本页收录的 52 个技能即其载体：一个自包含技能包装下整套库，由 CreateSkill 统一编排。

    Pulse 可观测Pulse

    随附的可观测面板，追踪系统运行与你的推进状态。

    安装方式

    LifeOS 由 AI 来安装——安装动作本身就是一句提示词

    路径做法
    AI 提示词（推荐）把 Read https://ourlifeos.ai/install and install LifeOS for me. 粘贴给 Claude Code、Cursor、Codex 等任意有能力的编码智能体，它会读取安装页并全程征求许可地完成配置
    终端一行命令macOS/Linux + Claude Code：curl -fsSL https://ourlifeos.ai/install.sh | bash
    依赖一个有能力的 AI 编码 harness（官方在 Claude Code 上构建与运行）+ bun
