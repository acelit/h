BACKGROUND产品老A

一个月，
三件事

理解这两家现在处境的钥匙，是过去一个月接连落地的三件事。

  • 六月 · DeepSeek
    拿了钱，几乎没让渡决定权

    成立以来首笔外部融资约 510 亿元，投后估值 3500–4000 亿元。梁文锋以"权钱分离"结构，引入腾讯、宁德时代等资金的同时，仍保留约 84% 股权与近乎全部表决权。

  • 同期 · Kimi
    准备把自己交给公开市场

    母公司月之暗面估值抬到约 315 亿美元，筹备港股上市，下一轮 pre-IPO 谈到 500 亿美元。阿里为第一大机构股东。两年融十几轮。

  • 昨天 · Anthropic
    价格不变，能力翻倍

    Claude Opus 5 定价与上代持平，Frontier-Bench 拿到 43.3%（上代 18.7%），OSWorld 用约 1/3 成本超越自家旗舰。这件事的意义，可能比两家各自那笔融资还大。

THE THESIS产品老A

不是趋同，
是补短板

"两家都在补自己最薄的那一半，于是在中间相遇——这就是外界看到的所谓'像'。" — 但补的方向，是相反的
Kimi / 产品公司最怕

基础模型掉队

一旦底座落后，所有产品体验会跟着塌。所以 Kimi 反复强调必须保持 SOTA、不惜推倒重训，K3 用上 2.8 万亿参数的新架构。

DeepSeek / 技术公司最怕

落地失焦

研究再强也需要一个能验证价值的出口。所以 DeepSeek 只敢从最确定的编程场景切一刀，直到 2026 年 3 月才成立 Agent Harness 团队补产品。

补完之后，各自回到原来的轨道上，只是身上多了一块以前没有的肌肉。补短板，是为了不被短板拖死，不是为了变成对方。

TWO LIFELINES产品老A

两条命根

这是最根本的一处区别，后面很多条都从这里长出来。

向左 · 增长做给投资人看

一条够陡的曲线

  • ARR 三月过 1 亿、五月过 2 亿、六月过 3 亿美元
  • API 收入占比超过七成
  • 海外付费用户增长约四倍

对 Kimi，涨价是好消息。

向右 · 效率做给同行看

一条够低的成本

  • V3 训练成本约 550 万美元
  • 推理成本压到行业平均的十分之一
  • 年化收入 4–5 亿、逾 20 万家企业接入

对 DeepSeek，降价才是好消息。

陡曲线必须一直陡下去，一旦减速估值立刻重算；成本优势维持住就有效——更耐用，也更沉默。

THE VERDICT产品老A

海外社区：
两种声音

从 Hacker News、Reddit 到 ChinaTalk、The Teardown 的公开讨论。

肯定 / What holds up
  • Kimi 的 ARR 曲线，是这年中国 AI 最干净的商业化证据，API 占七成说明企业真在付钱
  • MuonClip 被公认是 Moonshot 少有的硬创新
  • 从 Claude 切到 Kimi 只改一行 base URL，价格优势真实可感
  • DeepSeek 仍被视为"国产开源地基"的定义者
质疑 / What to watch
  • ARR 是运行率口径、非审计年收入，三个月翻三倍不可持续
  • K2 架构高度接近 DeepSeek-V3，原创主要是 MuonClip
  • K3 准确率升到 46% 的同时，幻觉率爬到 51%
  • 数据驻留与合规，是中国模型出海的明确天花板
THE NEW VARIABLE产品老A

Claude Opus 5
发布

Anthropic 发布 Claude Opus 5：价格和上一代一样，能力却翻了一倍多。它悄悄换掉了行业的比价尺子——过去比"每百万字多少钱"，现在比"做完同一件事，一共花多少钱"。模型越聪明，用的步骤和字数越少，单价就不再是重点。

对 Kimi 的冲击

低价优势被挤掉

  • Kimi 的卖点是"能力接近闭源、价格只要几分之一"
  • 如今闭源能力翻倍、价格没涨，这个差价被压扁
  • Kimi 自己还把 K3 涨到 3 美元，更显尴尬
  • 而 K3 出错率高达 51%，做 Agent 一步编错、后面全废，省下的价差又赔进去

正好打在它最痛的地方。

对 DeepSeek 的冲击

"便宜"不再独一份

  • DeepSeek 靠"极致便宜"立身
  • Opus 5 新增"用力档位"，贵模型也能调到便宜档干粗活，直接抢它的低价市场
  • 更关键：它证明把成本做低不是小公司的专利，钱多的一方认真做效率可能更快

长期动摇它的成本故事。

IS IT EXPENSIVE产品老A

315 亿美元，
贵不贵？

很多人第一反应是泡沫。要判断，得放进三个坐标。

公司估值 ÷ 收入口径倍数
Kimi / 月之暗面约 315 亿 ÷ ARR 约 3 亿≈105×
DeepSeek约 500 亿量级 ÷ 年化 4–5 亿≈100–125×
Anthropic（对标）约 9,650 亿 ÷ 年化约 470 亿≈20×
  • 坐标一跟 DeepSeek 比：同一数量级，其实一样贵——一级市场给两家头部的定价方法一致。
  • 坐标二跟美国比：差的不是倍数，是倍数的性质。20× 是成熟倍数，105× 是早期倍数——Kimi 约等于 Anthropic 一年半前的位置。
  • 坐标三跟自己增速比：涨价不掉量？海外能否续翻倍？算力跟不跟得上？不是高估，是高压。

数字为媒体报道中位区间；ARR 为运行率口径，不等于经审计年收入，也未扣成本；倍数为按公开数据估算，仅作量级参考。

A MISREADING产品老A

"越来越像"
是个误读

两家确实在互相靠，但把这读成趋同，忽略了三件事。

  • 其一

    靠拢是各自补短，不是想变成对方

    补的恰好是对方的长板、自己的短板。交叉点上短暂重合，交叉之后各自朝原方向继续走。

  • 其二

    终点不同，交叉之后必然再分开

    一个奔向跑通商业化、成功上市的公司；一个奔向一个被证明的命题。今天的重合是阶段性的，明天的分开是结构性的。

  • 其三

    最底层的分野：估值由谁定价

    Kimi 把定价权交给公开市场，永远有一面镜子照着自己；DeepSeek 把定价权留在手里，代价是没有那面镜子。
