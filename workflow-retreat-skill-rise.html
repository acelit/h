THE SILENCE · 静默

消失的
workflow截图

2025 下半年，做 AI 应用的人集体安静了——不是闷声发财，是"不好意思再提自己在画什么"。花花绿绿的节点连线、二十几步的流程图，全部蒸发。

因为隔壁那个从不画流程图的家伙，对话三句话就搞定了他画半小时才跑通的事。

用过 iPhone 的手，

THE MISTAKE · 错位

把"搭建过程"
当成了产品

workflow 最大的问题不是技术，是它把"构建过程"当核心价值，而非"完成任务"。打开它，先看到一张空白画布。

可用户想的是"帮我把事做了"，不是"给我画布让我画图"。这是一个致命的错位。

给你乐高→你搭→你有成就感。这套逻辑的隐含假设是"用户愿意花时间搭建"。2025 年的用户，不愿意了。

产品老A
THE DISTRUST · 不信任

Workflow是一份
"不信任书"

你雇了个名校毕业、反应敏捷的助理，却塞给他一份 200 步操作手册，不许跳步、不许变通——这是赋能，还是侮辱？

这就是 workflow 对大模型做的事。能力过了临界点，你还画流程图，等于给资深员工贴任务清单。

预设的分支，
盖不住真实世界。

产品老A
THE PIVOT · 转身

连旗手
都转身了

曾把"画布 + 插件市场"做到极致、几乎定义了国内 workflow 心智的扣子，已经悄悄换了一副面孔。

现在迎接你的不是空白画布，而是一个 AI 搭档：多 Agent 组队协作、接管开发与创作、你说一句话它去干活。

旗手放下了旗帜，
风往哪吹，不必再问。

05
产品老A
THE PROTOCOL · 协议

插件市场
的黄昏

"我们有 3000 个插件"曾是硬卖点。但 MCP 协议的普及，正让"插件"这个概念本身变得可笑。

任何服务只要暴露标准接口，agent 就能直接调用——不必封装、不必上架、不必搜索安装。

MCP 之于插件市场，
如互联网之于黄页。

产品老A
THE RISE · 崛起

Skill
为什么崛起

agent 原生产品把使用门槛压到零：不必懂"节点""触发器""条件分支"，会说人话就行。

而真正让它可持续的，是底层单元变了：workflow 编码"过程知识"（脆），skill 编码"领域知识"（鲁棒可组合）。

怎么走，交给 agent 当场判断。

07
产品老A
THE CURVE · 曲线

线性
vs 指数

workflow 平台是线性增长：每做一个新流程，只解决一个特定场景，做一百个解决一百个。

skill 驱动的 agent 是指数增长：每沉淀一个 skill，都能被无数种组合方式即时调用。

一个是加法，
一个是乘法。

08
产品老A
THE TRANSITION · 退位

退位，
不等于死亡

workflow 不会消失，它只是从"前台主角"退到"幕后机制"——在资金、合规、审批等环节兜底确定性。

但它不该再暴露给用户，更不该是对外标榜的卖点。前台交给自然语言，后台交给 workflow。

承认"最引以为傲的东西放错了位置"，需要的勇气远超技术挑战。能转身的，都值得尊敬。

THE TIDE · 潮水

潮水
退去之时

方向变了，肯转身，
就还在牌桌上。

诺基亚做对了功能机的一切，柯达发明了数码相机——区别只在于有没有及时转身。而 skill 与 agent，正安安静静地，把一切重新组织起来。
