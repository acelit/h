一句话立场

自研模型常常是虚荣，
控制路由才是生意。

创始人 Alex 把自己创业至今「最严重的战略误判」摊开讲：曾被硅谷的狂热裹挟，天真以为在跑分上争第一就能形成商业壁垒。如今他反转了这句话——

过去的信仰技术虚荣

刷 Benchmark、争「全球第一模型」，把自研基座当成公司身份的象征。跑分狂欢，很大程度是大厂维持估值的一场心理战。

现在的判断真实护城河

应用层的护城河不是某一颗模型，而是任务入口、工作流，和「哪个节点调用哪颗模型」的调度权。谁握有路由，谁就握有毛利与生死。

他把这套能力命名为 Tokenomics：客户提出商业目标，平台用尽量少的 Token、在毫秒级匹配性价比最高的那颗模型。

§02 · 靠分发，不靠买量

增长抓手很纯粹：确保全网视觉水准最高、转化最强的商业广告，都由这台引擎渲染，再把大片背后的完整工程流拆解开、公开展示。

他曾在大型科技企业的技术核心层工作，理解这台官僚机器：中层与高管要向董事会和华尔街证明季度进展，只能依赖量化跑分。他甚至点破——有人暗中把测试数据混入训练集，或精调裁判模型，形成 LLM-as-a-Judge 的作弊循环。

观察真实 API 调用后他的判断：北美传统巨头里在基座层真正还有统治力的，他眼里只剩 Google；中国市场的腾讯、小米、阿里、字节，落地竞争力更强，对虚荣跑分的痴迷也没那么病态。

§03 · Benchmark 之争产品老A
§03 · Tokenomics

毛利 80% 还是 20%，
取决于谁握有路由权。

80%+
可控开源权重 + 垂直后训练 + 动态路由的综合毛利率
20–30%
只是前端套壳、透传闭源 API 时的毛利率

视觉营销赛道和编程不同：一条病毒短视频不需要博士后级推理，核心是「成本无限低、结果绝对可控」。当系统替客户判断每个节点调用哪颗模型、用最少 Token 交付，请求调度权就成了生死战——目前全网生产请求中，超过 40% 的模型路由已由系统自主分流。

自研也有红线：只有一线捕捉到尖锐、垂直、确定性高、且客户愿用真金白银提刚需的工业场景，才亲自训练专属模型——而不是创始人想征服全球通用基座的虚荣心。

曾有非技术背景的创意员工，单周用代码生成工具烧掉超 3 万美元，连续五个晚上自建自动化工具，打穿了工程与设计之间的痛点。

§04 · 分发终局

技术优势会过去，

决定超额价值终极流向的核心枢纽，
永远只有分发权——

从 Snap 的衰落里，他学到的最痛一课是：任何公司都不能把一时的狂暴增长当成永久优势。App 层能穿越周期的护城河只有两条——对客户终极业务交付结果负全责，以及建立网络效应：让新用户能在上一位大师沉淀的高阶工程上二次创作。官方引导的第一批开源视觉项目种子，八周内从约 10 个涨到突破 1 万个。

Shopify 曾是中小企业独立电商的水电煤；Higgsfield 从第一天起的野心，是成为全球品牌与创作者构建流量与内容分发的基础设施。一年预测 45 亿美元是保守账本，他本人真正笃定的数字，是击穿 100 亿。
