§01 · 七天时间线

三家公司，七天，
同一层归零。

  • 8.13 DeepSeek：发布 Harness v0.1（MIT），公开对标 Claude Code。V4-Pro 原生支持 OpenAI Responses API。
  • 8.18 Block：开源 Berd——一个界面同时管 Goose、Claude Code 和 Codex。
  • 8.18 Anthropic：Claude Code CLI v2.1.229，p99 CPU 从 24% 压到 10%。
  • 8.19 OpenAI：发布《Codex as a platform》，宣布 harness 开源为标准。

「你没法卖一样马上就要免费的东西。你只能决定——要不要当那个把它送出去的人。」

时间差只有六天。把它理解成 OpenAI 主动出招，会误判它的处境。更准确的说法是：它抢在别人之前，把一个已经保不住的东西送出去，并且要求署名。

开源 harness，把模型竞争从平台战争，降级成了零件比价。

DeepSeek 让自己的 API 去兼容 OpenAI 的 schema，Responses API 的规范由多厂商组织治理。标准委员会几乎从不推翻发起者的架构——它们的工作是把它固化下来、发给全行业。

§04 · 标准 / STANDARD产品老A
§05 · 送中间，收两头

免费修高速公路，
两头收过路费。

  1. 底层：模型 + 算力 + 托管
    收钱且不开源。发动机锁在自己车间里。
  2. 中间：agent 循环 / 协议 / SDK
    免费送出（MIT/Apache 2.0）。本来就快没定价权了。
  3. 上层：~10 亿月活 + 结算 + 广告 API
    收钱且不开源。ChatGPT 入口 + Commerce / Ads API。

「路修得越好、跑的车越多，两头越赚钱。修路本身赚不赚钱，根本不重要。」

§05 · 模式 / BIZ MODEL产品老A
§06 · 做 Harness 创业公司怎么办

从 8.19 起，
融资材料需要重写。

agent 执行循环、客户端协议、SDK、示例应用——全免费。那还剩什么能做？

  1. 垂直上下文 + 工具
    报税、安全事件响应、供应链调度——OpenAI 自己点名说这些归你。
  2. 评测与可观测
    agent 跑错了怎么发现、怎么归因、怎么回归测试——还没标准答案。
  3. 跨模型编排层
    Block 的 Berd 方向——但它自己也开源了，说明也很难直接卖钱。
