01skill 介绍

GitHub · gzh-design-skill
WHAT IS IT

公众号排版
自动化引擎

把 Markdown 直接转成能粘贴进公众号编辑器的精排 HTML，从主题库里挑风格，剩下的它全包了。

🎨内置主题风格库，一句话切换整篇观感
🔢自动章节编号、关键词下划线、引言卡片、目录导航
📥支持 MD / Word / PDF 输入，还能自定义主题

HOW TO INSTALL

三步装好
零基础也会

1
在 GitHub 找到 Skill 仓库
找到 isjiamu/gzh-design-skill 在 GitHub 的项目链接
2
一键安装 skill
将链接发给 Codex / Claude / Qoder / WorkBuddy 等办公工具，自动安装
3
发一句话就能用
丢给它一篇 Markdown：帮我用 gzh-design 排版 即可
TIP装好后不用记命令，直接把文章甩给它、说出想要的风格就行。
