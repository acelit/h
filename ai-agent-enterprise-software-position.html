§01 · 实证 / PRICING产品老A

还没变的，
是席位数量。

迄今没有任何厂商披露过
因 AI 导致的实际席位数下降。

—— NARRATIVE ≠ REPORT

反向证据同样是硬披露：微软把 Copilot 打进全线套件的同时全球涨价（E3 +13%、F1 +33%），而 Copilot 付费席位半年内破 3000 万。Atlassian 坚守 per-seat，AI 用户席位反而扩张更快。

分层结论：定价范式的转移已经实证发生；席位数量的崩塌，迄今主要停留在叙事与估值层面。

§03 · 迁移 / THREE LAYERS产品老A

中间那层，
叫 agentic 套利。

2340 亿美元
从现在到 2030 年累计暴露于 agentic 套利的企业应用支出（Gartner）

一个 Agent 拉 CRM、更新 ERP、出报表、发通知——「人一个应用都不用打开」。它同时打掉两件事：界面作为差异化因素，以及「每多一个用户就多一份收入」这个二十年的 SaaS 核心前提。

到 2030 年，这一规模约相当于企业应用 SaaS 支出的 20%。钱不会消失，会被在位者自我蚕食、被横向 agentic 平台夺取。

§03 · 官方口径 / GARTNER产品老A

三条护城河，
只有一条是真的。

  1. 国产替代 · 有限窗口
    已替换 300 余家国际厂商系统、一级央企签 55 家。真实，但是一次性替换红利，给的是时间不是护城河。
  2. 实施与交付 · 伪护城河
    这是成本结构不是壁垒，且是 AI 最擅长压缩的一层——国内 AI Agent 交付周期 6–12 月，反长于传统 ERP 的 3–6 月。
  3. 本地财税合规与权限 · 真壁垒·未兑现
    唯一符合「模型到了也绕不开」的一条。方向对（YonOnto / YonAIG），但连定价与计费机制都还没披露。

§06 · 样板 / PALANTIR产品老A

抄岗位容易，
抄机制极难。

FDE碎石路→高速公路

现场定制经中央工程团队硬化为可复用产品能力，下个客户不必从零开始。人力不进 COGS，毛利仍 85%。

实施顾问交付即离场

认知随人员流动蒸发，每个项目从零开始。以人天计费，毛利率通常仅 20–35%。

分水岭不在「派不派人进现场」，在现场认知有没有制度化通道流回产品。FDE 若挂在实施部门而非产品部门，反馈回路就断了——最终变成「带更漂亮前端的 Accenture」。

§06 · 机制 / FDE产品老A

四个指标，
判断真假转型。

抄到机制
  • 人均创收随收入加速抬升，而非随人头线性增长
  • 毛利率因定制复用突破 33.5%
只抄岗位
  • 现场定制转标准功能的比例停滞，碎石路铺不成高速路
  • 软件订阅占比不升反降，服务始终是主营

位置错位的代价，
远大于价值不足的代价。

§06 · 判据 / SIGNALS产品老A

还有机会吗？
分四门回答。

  • 许可 + 席位 → 正在关闭，许可收入 −19.55%，前提已被打破。
  • 中低端标准化 SaaS → 已经关闭，位置属于平台。
  • 记录系统 + 约束引擎 → 机会在，被 Agent 抬高门槛；用友最缺的恰是产品化能力。
  • 结果交付商 → 机会最大也最难，生死线是四个指标而非单一毛利率。
